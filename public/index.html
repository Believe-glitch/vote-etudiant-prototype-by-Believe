Comment ça marche

1

Je reçois mon code

Chaque inscrit reçoit un code unique chez l’officiel chargé des codes, ou en auditoire.

2

Je vote

Pendant la séance, je tape mon code et je vote pour chaque poste de ma promotion et pour la présidence.

3

Les résultats

À la fin du décompte, le vote se ferme. Les résultats sont dévoilés à tous en même temps.
